# core/arg.sh

引数をパースするための Neobash コアライブラリ。

## 概要

このライブラリを使うと、bash スクリプトや関数のコマンドラインオプションを定義してパースできます。
必須オプションと任意オプション、オプションのエイリアス、デフォルト値、型チェックに対応しています。
また、オプションの使用法テキストを自動生成することもできます。

「-h」または「--help」が渡されると、ユーザーが定義した「show_help」関数が実行されます
（「show_help」が定義されていない場合は「core::arg::show_usage」が実行されます）。
「-v」または「--version」が渡されると、ユーザーが定義した「show_version」関数が実行されます。

サポートされている引数の型は「string」「int」「bool」です。パース時に値が検証されます。

### 初期化

スクリプトの引数をパースする場合は、以下のコマンドでライブラリを初期化してください。

```bash
arg::init_global
```

関数内で引数をパースする場合は、以下のコマンドでライブラリを初期化してください。

```bash
arg::init_local
```

### core::arg::add_option

オプションの仕様を定義します。
* エイリアスは「arg::add_option」として定義されています。
* 変数は事前に「core::arg::init_global」または「core::arg::init_local」で初期化する必要があります。
* 「-h」「--help」「-v」「--version」は予約済みのため、オプション名として使用できません。

#### オプション

* **-l \<value\>**

  (string)(必須): オプションを識別するためのラベル名。

* **-o \<value\>**

  (string)(必須): オプション名。例: 「-m」「--myarg」。

* **-t \<value\>**

  (string)(任意): オプションの型。「string」「int」「bool」のいずれかを指定します。デフォルト: 「string」。

* **-r \<value\>**

  (bool)(任意): オプションが必須かどうか。「true」または「false」を指定します。デフォルト: 「false」。

* **-d \<value\>**

  (string)(任意): オプションが指定されなかった場合に使用されるデフォルト値。デフォルト: 「string」の場合は「""」、「int」の場合は「0」、「bool」の場合は「false」。

* **-s \<value\>**

  (string)(任意): ストレージモード。「none」「true」「false」のいずれかを指定します。「none」の場合は値を必要とし、「true」または「false」の場合はフラグとして動作します。デフォルト: 「none」。

* **-h \<value\>**

  (string)(任意): オプションのヘルプメッセージ。デフォルト: 「no help message for this option」。

#### 終了コード

* **0**: 成功した場合。
* **1**: 失敗した場合。

#### 標準出力

* なし。

#### 標準エラー出力

* エラーおよびデバッグメッセージ。

### core::arg::add_option_alias

オプションのエイリアスを定義します。
* エイリアスは「arg::add_option_alias」として定義されています。
* オプションは事前に「core::arg::add_option」で定義しておく必要があります。
* 「-h」「--help」「-v」「--version」は予約済みのため、エイリアスとして使用できません。
* ラベルごとにエイリアスは1つだけ定義できます。

#### オプション

* **-l \<value\>**

  (string)(必須): 「arg::add_option」で定義したラベル。

* **-o \<value\>**

  (string)(必須): オプションのエイリアス名。例: 「--myarg」に対する「-m」。

* **-a \<value\>**

  (string)(非推奨): 「-o」の非推奨なエイリアスです。代わりに「-o」を使用してください。

#### 終了コード

* **0**: 成功した場合。
* **1**: 失敗した場合。

#### 標準出力

* なし。

#### 標準エラー出力

* エラーおよびデバッグメッセージ。

### core::arg::parse

引数をパースします。
* エイリアスは「arg::parse」として定義されています。
#### 予約済みオプション
* 「-h」または「--help」: ユーザーが定義した「show_help」関数を実行します（「show_help」が定義されていない場合は「core::arg::show_usage」が実行されます）。
* 「-v」または「--version」: ユーザーが定義した「show_version」関数を実行します。
#### 入力値の検証
「int」型のオプションに整数以外の値を渡した場合、または「bool」型のオプションに「true」/「false」以外の値を渡した場合、エラーになります。定義されていないオプションを渡した場合もエラーになります。
#### 残りの引数
引数に「--」が渡されると、その後のすべての引数が「ARG_OTHERS」配列に格納されます。
##### 例
* 引数を「-a 1 -b 2 --c 3 ddd eee fff」とした場合、「ARG_OTHERS=(ddd eee fff)」が設定されます。
* 引数を「-a 1 -- -b 2 --c 3 ddd eee fff」とした場合、「ARG_OTHERS=(-b 2 --c 3 ddd eee fff)」が設定されます。

#### 引数

* **...** (string): すべての引数。「"$@"」として渡してください。

#### 終了コード

* **0**: 成功した場合。
* **1**: 失敗した場合。

#### 標準出力

* 「-h」または「--help」が指定された場合はヘルプテキスト、「-v」または「--version」が指定された場合はバージョン情報。

#### 標準エラー出力

* エラーおよびデバッグメッセージ。

### core::arg::show_usage

スクリプトのヘルプテキストに埋め込むためのオプション使用法を表示します。
* エイリアスは「arg::show_usage」として定義されています。
* この関数は、スクリプトのヘルプメッセージにオプションの使用法を埋め込むために設計されています。

#### 引数

* **$1** ((string)(任意):): 使用法の出力をインデントするための行プレフィックス。「core::arg::set_help_prefix()」でも設定できます。デフォルト: 「""」。

#### 終了コード

* **0**: 成功した場合。

* オプションの使用法メッセージ。
