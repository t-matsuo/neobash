### os::check_var

変数が定義されているかどうかを確認します

#### オプション

* **--name \<string\>**

  標準出力に割り当てる変数名。指定しない場合、メッセージは標準出力に出力されます。（必須）

* **-n \<string\>**

  --name のエイリアス

* **--enable-error \<bool\>**

  true の場合、変数が定義されていない時にエラーメッセージを出力します。（任意）デフォルト: ``true``

* **-r \<bool\>**

  --enable-error のエイリアス

* **--exit \<bool\>**

  true の場合、変数が定義されていない時に return 1 の代わりに exit 1 します。（任意）デフォルト: ``false``

* **-e \<bool\>**

  --exit のエイリアス

#### 終了コード

* **0**: 変数が定義されています
* **1**: 変数が定義されていません

#### 標準出力

* なし

#### 標準エラー出力

* 変数が定義されておらず、--enable-error が true の場合にエラーメッセージを出力します
