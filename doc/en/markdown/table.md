### markdown::csv2table

Convert csv to markdown table

#### Options

* **--header \<string\>**

  table header csv (required)

* **--data \<string\>**

  table data csv (required)

* **--line-break \<string\>**

  replacement string for line breaks in quoted csv fields (default: <br>)

#### Exit codes

* 0

#### Output on stdout

* table

#### Output on stderr

* None
